# رله AUT

اینترنت دانشگاه را به یک VPN شخصی تبدیل کنید. این پروژه اتصال دانشگاه شما را از طریق یک سرور مجازی (VPS) تانل میکند تا اینترنت آزاد و بدون محدودیت را روی گوشی یا سایر دستگاه‌های شما فراهم کند. این سیستم به صورت خودکار اکانت‌های دانشجویی شما را مدیریت و جابه‌جا می‌کند تا همیشه بالاترین سرعت را داشته باشید. برای استفاده از این پروژه به یک کامپیوتر روشن در دانشگاه و یک سرور ایران نیاز دارید.

> 💡 **ایده اصلی:** درواقع شما با روشن گذاشتن یک لپتاپ یا کامپیوتر ویندوزی توی دانشگاه که فقط به اینترنتش متصله، میتونید همیشه از هرجایی به اینترنت آزاد دانشگاه دسترسی داشته باشید. این کاری بود که باید مثل دانشگاه های بهشتی، علم و صنعت، و.. خود بخش انفورماتیک دانشگاه انجام میداد ولی خب چون نداد میتونید خودتون راه بندازیدش، مخصوصا دانشجو های خوابگاهی که نمیتونن در شرایط فعلی حضوری به تهران بیان فقط برای استفاده از تبعیض ایجاد شده برای اتصال به اینترنت.
> 
> فقط نیاز به خرید یک سرور داخلی ایران دارید (بسیار به صرفه تر از خرید vpn یا حتی در شرایطی اینترنت پرو). حتی میتونید چند نفری با روشن گذاشتن یک کامپیوتر و اضافه کردن اکانت های اینترنت خودتون (یا سال بالایی هاتون که از دانشگاه رفتن یا فارغ التحصیلان) هزینه رو بین همدیگه تقسیم کنید. نکته دیگه اینکه حتما از همون کانفیگ های V2ray که قبلا باهاشون وصل میشدن تست بگیرید و توی برنامه اد کنید. موفق باشید، ورژن های بعدی در راهه.

## 📋 پیش‌نیازها (قبل از شروع)

1. **یک سرور مجازی (VPS) ایران**: به یک سرور لینوکس (اوبونتو پیشنهاد می‌شود) در ایران نیاز دارید. می‌توانید از سایت آرون‌کلاد تهیه کنید.
2. **پایتون (Python)**: باید پایتون (نسخه 3.4 یا جدیدتر) روی ویندوز شما نصب باشد.
    * *توجه: ویزارد راه‌اندازی برای اجرا به پایتون نیاز دارد، پس ابتدا آن را نصب کنید!*
3. **شبکه دانشگاه**: سیستم شما باید به شبکه دانشگاه امیرکبیر (AUT) متصل باشد.

## 🚀 شروع سریع (۳ مرحله)

### مرحله ۱: راه‌اندازی ویندوز (لوکال)
۱. **پیش‌نیازها**: مطمئن شوید که **آی‌پی سرور مجازی** خود را دارید و **پایتون** روی سیستم شما نصب است.
۲. **انتخاب نسخه**:
   * اگر کامپیوتر جدید دارید (ویندوز ۱۰/۱۱)، پوشه `VLESS_Server_64bit` را باز کنید.
   * اگر کامپیوتر قدیمی دارید (ویندوز ۷ یا ۳۲ بیت)، پوشه `VLESS_Server_32bit` را باز کنید.
۳. **اجرای برنامه**: درون پوشه انتخابی، فایل **`Start_Server.bat`** را اجرا کنید.
۴. **ویزارد وب**: اسکریپت به صورت خودکار مرورگر شما را باز کرده و به پنل راه‌اندازی در آدرس `http://127.0.0.1:3080` می‌رود.
۵. **ساخت تنظیمات و نصب خودکار**: 
   * آی‌پی سرور، نام کاربری و رمز پورتال دانشگاه و رمز داشبورد خود را وارد کنید.
   * ✨ **جدید:** تیک گزینه **"Automate VPS Setup (SSH)"** را بزنید، رمز root سرور خود را وارد کنید تا ویزارد به صورت خودکار تمام مراحل نصب را روی سرور شما انجام دهد!
۶. **پایان**: اگر نصب خودکار را انتخاب کردید، منتظر پیام موفقیت بمانید. اگر نصب دستی را انتخاب کردید، ویزارد یک کد به نام **VPS Configuration** به شما نشان می‌دهد که برای مرحله بعد نیاز است.

---

### مرحله ۲: راه‌اندازی سرور مجازی (اگر از نصب خودکار استفاده نکردید، این مرحله را رد کنید)

*اگر در مرحله قبل تیک "Automate VPS Setup" را زده‌اید، اینترنت آزاد هم‌اکنون روی سرور شما نصب شده است! مستقیماً به **مرحله ۳** بروید.*

اگر ترجیح می‌دهید سرور را به صورت دستی تنظیم کنید، به سرور لینوکس ایران خود SSH بزنید و این مراحل را دنبال کنید:

#### الف. دانلود و استخراج FRP
یکی از روش‌های زیر را برای دانلود FRP روی سرور خود انتخاب کنید:

> **روش ۱: گیت‌هاب (استاندارد)**
> ```bash
> wget -O frp.tar.gz https://github.com/fatedier/frp/releases/download/v0.61.1/frp_0.61.1_linux_amd64.tar.gz
> ```

> **روش ۲: میرور ایرانی (اگر گیت‌هاب مسدود یا کند است)**
> ```bash
> wget -O frp.tar.gz https://scorpian.ir/proxy/asset/fatedier/frp/213672059
> ```

> **روش ۳: نصب دستی (WinSCP/SFTP)**
> اگر دستورات بالا کار نکرد، فایل `frp_0.61.1_linux_amd64.tar.gz` (یا نسخه `v0.51.3` برای ۳۲ بیت) را روی کامپیوتر خود دانلود کرده و با برنامه هایی مثل **WinSCP** یا **Termius** به سرور منتقل کنید.

**استخراج فایل‌ها:**
```bash
tar -xzf frp.tar.gz && mv frp_0.61.1_linux_amd64 frp && chmod +x frp/frps
# توجه: اگر از نسخه v0.51.3 استفاده می‌کنید نام پوشه متفاوت خواهد بود
```

#### ب. اعمال تنظیمات
این دستور را اجرا کنید، **کد کپی شده از ویزارد را پیست کنید** و سپس کلیدهای **`Ctrl+D`** را بزنید تا ذخیره شود:

```bash
# برای نسخه ۶۴ بیت (v0.61.1+):
cat > frp/frps.toml

# برای نسخه ۳۲ بیت (v0.51.3):
# cat > frp/frps.ini
```

#### ج. تنظیم شروع خودکار (سرویس)
کل این بلوک را کپی و پیست کنید تا تونل همیشه فعال بماند و اجازه دسترسی به پورت ۴۴۳ را داشته باشد:

```bash
# تنظیم دسترسی برای پورت ۴۴۳
sudo setcap 'cap_net_bind_service=+ep' $(pwd)/frp/frps

# ساخت فایل سرویس
CUR_DIR=$(pwd)
sudo tee /etc/systemd/system/frps.service > /dev/null <<EOF
[Unit]
Description=FRP Server
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=$CUR_DIR/frp
ExecStart=$CUR_DIR/frp/frps -c $CUR_DIR/frp/frps.toml
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload && sudo systemctl enable frps && sudo systemctl restart frps
```

### مرحله ۳: اتصال گوشی

1. یک اپلیکیشن **سازگار با VLESS** روی گوشی خود نصب کنید (مثل **Karing**, **v2rayNG** یا **v2rayN**).
2. **لینک VLESS** که در پایان راه‌اندازی به شما داده می‌شود را کپی و در اپلیکیشن وارد کنید.
3. **متصل شوید** و از اینترنت آزاد لذت ببرید!

## 🛠 داشبورد و مدیریت

شما می‌توانید اکانت‌ها و سرورهای خود را از طریق مرورگر مدیریت کنید:

*   **داخلی:** `http://127.0.0.1:3080`
*   **از راه دور:** `http://YOUR_VPS_IP:8880`

### 🔄 مانیتورینگ و کنترل

*   **وضعیت تونل**: وضعیت اتصال به سرور مجازی به صورت لحظه‌ای در داشبورد نمایش داده می‌شود.
*   **بازیابی تنظیمات**: اگر کد VPS را گم کردید، می‌توانید همیشه از بخش **VPS Config** در داشبورد آن را بازیابی کنید.
*   **چرخش خودکار**: سیستم به صورت خودکار بین اکانت‌های دانشجویی شما سوئیچ می‌کند تا همیشه بهترین سرعت را داشته باشید.

## 🧹 چگونه ریست کنیم؟

اگر می‌خواهید تمام داده‌های خود را پاک کنید، در داشبورد روی دکمه **Factory Reset** کلیک کنید. این کار تمام تنظیمات را حذف کرده و اجازه می‌دهد دوباره از ابتدا مراحل را طی کنید.

---

## ❓ عیب‌یابی

*   **برنامه باز نمی‌شود؟** مطمئن شوید پایتون نصب است و تیک "Add to PATH" را هنگام نصب زده‌اید.
*   **اینترنت وصل نیست؟** چک کنید که در پنل مدیریت سرور مجازی (فایروال ابری)، پورت‌های **443** و **8880** باز باشند.
*   **خطای اتصال؟** مطمئن شوید برنامه دیگری (مثل Nginx) از پورت 443 سرور شما استفاده نمی‌کند.
