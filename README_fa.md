# AUT Relay

AUT Relay یک راهکار پروکسی متن‌باز است که اتصال شبکه دانشگاه شما را به یک سرور مجازی (VPS) خارجی متصل (Bridge) کرده و دسترسی بدون محدودیت به اینترنت را فراهم می‌کند. این سیستم دارای یک رابط کاربری وب مدرن، مدیریت چندکاربره و یک لود بالانسر هوشمند است که به صورت پویا اکانت‌های دانشجویی را تغییر می‌دهد تا مصرف پهنای باند بهینه شده و همواره بالاترین سرعت اتصال حفظ شود.

> 💡 **ایده اصلی:** با روشن گذاشتن یک لپ‌تاپ یا کامپیوتر متصل به شبکه داخلی در دانشگاه، می‌توانید از هر کجای ملانت به اینترنت بدون محدودیت دانشگاه دسترسی داشته باشید. این ویژگی به خصوص برای دانشجویان خوابگاهی که نمی‌توانند برای استفاده از اینترنت مستقیماً به دانشگاه مراجعه کنند، بسیار کاربردی است.
>
> تنها چیزی که نیاز دارید یک سرور مجازی (VPS) ایران است (که در بسیاری از موارد از خرید VPN یا بسته‌های اینترنت پرو بسیار مقرون‌به‌صرفه‌تر است). شما می‌توانید با دوستان خود هماهنگ شوید، یک کامپیوتر را روشن بگذارید و چندین اکانت دانشجویی (حتی اکانت‌های سال‌بالایی‌ها یا فارغ‌التحصیلان) را وارد سیستم کنید تا هزینه‌ها تقسیم شود. لود بالانسر داخلی بقیه کارها را انجام می‌دهد!

## 🚀 نحوه راه‌اندازی

### مرحله ۱: راه‌اندازی سرور (لوکال)

1. پوشه دانلود شده `AUT-Relay-Universal` را استخراج (Extract) کنید.
2. فایل **`Start_Server.bat`** را اجرا کنید.
3. اسکریپت به صورت خودکار **ویزارد راه‌اندازی اولیه** را در مرورگر شما در آدرس `http://127.0.0.1:3080` باز می‌کند.
4. مراحل ویزارد را دنبال کنید تا اطلاعات اولیه اکانت دانشگاه، آی‌پی سرور مجازی و اکانت ادمین داشبورد خود را تنظیم کنید.

### مرحله ۲: کانفیگ سرور مجازی (تنظیمات دستی)

پس از تکمیل ویزارد تحت وب، یک بلوک پیکربندی (Config) برای سرور مجازی خود دریافت خواهید کرد. از طریق SSH به سرور مجازی خود متصل شوید و دستورات زیر را برای نصب و پیکربندی تونل FRP اجرا کنید:

1. **دانلود و استخراج FRP:**

   ```bash
   wget -O frp.tar.gz https://github.com/fatedier/frp/releases/download/v0.61.1/frp_0.61.1_linux_amd64.tar.gz
   tar -xzf frp.tar.gz && mv frp_0.61.1_linux_amd64 frp && chmod +x frp/frps
   ```

2. **اعمال پیکربندی:**
   دستور زیر را اجرا کنید، بلوک پیکربندی تولید شده از ویزارد وب را در ترمینال پیست (Paste) کرده و سپس `Ctrl+D` را فشار دهید:

   ```bash
   cat > frp/frps.toml
   ```

3. **راه‌اندازی سرویس:**

   ```bash
   sudo setcap 'cap_net_bind_service=+ep' $(pwd)/frp/frps
   CUR_DIR=$(pwd)
   sudo tee /etc/systemd/system/frps.service > /dev/null <<EOF
   [Unit]
   Description=FRP Server
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=$CUR_DIR/frp
   ExecStart=$CUR_DIR/frp/frps -c $CUR_DIR/frp/frps.toml
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   EOF

   sudo systemctl daemon-reload && sudo systemctl enable frps && sudo systemctl restart frps
   ```

### مرحله ۳: بهینه‌سازی سرعت (BBR) [پیشنهادی]

برای رسیدن به بالاترین سرعت و کمترین تاخیر (Latency)، پیشنهاد می‌شود قابلیت **BBR** را روی سرور مجازی خود فعال کنید. این دستورات را در ترمینال سرور مجازی اجرا کنید:

```bash
echo "net.core.default_qdisc=fq" | sudo tee -a /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```
برای اطمینان از فعال بودن، دستور `sysctl net.ipv4.tcp_congestion_control` را اجرا کنید. خروجی باید شامل کلمه `bbr` باشد.

### مرحله ۴: اتصال و مدیریت

1. یک **اپلیکیشن سازگار با VLESS** روی گوشی/دستگاه خود نصب کنید (مانند **v2rayNG**، **v2rayN**، **Shadowrocket**، **Karing**).
2. در بخش **Users** داشبورد، لینک اشتراک (Subscription) را کپی کرده یا کد QR را اسکن کنید.
3. متصل شوید و از دسترسی آزاد لذت ببرید!

## 🌍 عبور از مسدودسازی آی‌پی (پشتیبانی از CDN)

اگر آی‌پی سرور مجازی شما مسدود یا محدود شده است، می‌توانید با استفاده از یک CDN (مانند آروان‌کلاد) این محدودیت را دور بزنید:

1. یک دامنه تهیه کرده و آن را در آروان‌کلاد ثبت کنید.
2. دو **رکورد A** ایجاد کنید که به آی‌پی سرور مجازی شما اشاره کنند:
   * **`@` (یا یک ساب‌دامین)** برای تونل اصلی (استفاده از پورت `8080`).
   * **`panel`** برای دسترسی به داشبورد (استفاده از پورت `8880`).
3. آیکون ابر/پروکسی ☁️ را برای این رکوردها روشن کنید تا ترافیک شما از طریق CDN هدایت شود.

## 🛠 ویژگی‌ها

این سیستم دارای یک **کنسول مدیریت پیشرفته** است که از طریق `http://127.0.0.1:3080` (یا از راه دور از طریق `http://YOUR_VPS_IP:8880`) در دسترس است.

### 📊 نمای کلی و مانیتورینگ

* **توپولوژی زنده:** جریان اتصال خود را از گره دانشگاه (Campus)، از طریق پل (Bridge)، تا استخر خروجی VPN به صورت بصری مشاهده کنید.
* **سلامت هاست و شبکه:** مانیتورینگ بومی و سبک برای مصرف پردازنده (CPU) و رم سیستم میزبان.
* **ترمینال سیستم:** لاگ‌های داخلی سیستم را با رنگ‌بندی تفکیک‌شده به صورت زنده در مرورگر خود ببینید.

### ⚖️ لود بالانسر و جابه‌جایی اکانت‌ها

این سیستم شامل یک `AccountRotator` هوشمند است که با اکانت‌های AUT شما مانند یک استخر منابع برخورد می‌کند:

* **استفاده پلکانی:** سیستم ابتدا حجم روزانه، سپس هفتگی، ماهانه و در نهایت حجم آزاد را مصرف می‌کند.
* **محدودیت‌های نشست (Session Limits):** می‌توانید یک **حجم نشست (Session Balance)** تعیین کنید (مثلاً ۱.۰ گیگابایت). سیستم پس از مصرف این مقدار در یک نشست، اکانت را تغییر می‌دهد.
* **آستانه‌های پویا (Dynamic Thresholds):** می‌توانید محدودیت‌های حجمی (GB) را دقیقاً از طریق تنظیمات شخصی‌سازی کنید.

### 👥 مدیریت چندکاربره

برای دوستان یا هم‌اتاقی‌های خود کاربران جداگانه بسازید:

* محدودیت حجم دقیق (مثلاً ۵۰ گیگابایت) و تاریخ انقضای پویای "روزهای باقی‌مانده" تنظیم کنید.
* اتصال مستقیم (Direct) و قابلیت‌های CDN را برای هر کاربر فعال یا غیرفعال کنید.
* لینک‌های اشتراک VLESS و کدهای QR اختصاصی تولید کنید.
* ردیابی دقیق مصرف حجم که مستقیماً از بک‌اند با داشبورد همگام‌سازی می‌شود.

### ⚙️ پنل کنترل سیستم

* **اتصالات (Connectivity):** دامنه داشبورد/اشتراک، آی‌پی سرور و پورت‌ها را مدیریت کنید.
* **نگهداری و بکاپ:** با یک کلیک از تمام پیکربندی سیستم خود در یک فایل خروجی (Export) بگیرید و وارد (Import) کنید.
* **منطقه خطر (Danger Zone):** کل سیستم را با یک کلیک به تنظیمات کارخانه بازگردانید و همه داده‌ها را پاک کنید.

## ❓ سوالات متداول و عیب‌یابی

**سوال: داشبورد باز نمی‌شود. چه کار کنم؟**
پاسخ: مطمئن شوید که پایتون نصب شده و به PATH سیستم شما اضافه شده باشد. همچنین بررسی کنید که فایل `Start_Server.bat` بدون کرش شدن فوری در حال اجرا باشد.

**سوال: خطای "VPS Tunnel Disconnected" در داشبورد مشاهده می‌شود. دلیل چیست؟**
پاسخ: بررسی کنید که فایروال سرور مجازی شما اجازه ورود به پورت‌های **443 (TCP و UDP)** (برای FRP) و **8880 (TCP)** (برای داشبورد) را می‌دهد. همچنین آنلاین بودن سرور خود را بررسی کنید.

**سوال: رمز عبور داشبورد را فراموش کرده‌ام. چگونه آن را ریست کنم؟**
پاسخ: اگر می‌توانید لاگین کنید، از گزینه "System Wipe" در منطقه خطر استفاده کنید. در غیر این صورت پوشه `config` را به صورت دستی پاک کرده و فایل `Start_Server.bat` را دوباره اجرا کنید تا تنظیمات شما از ابتدا ساخته شود.
