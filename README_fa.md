# پل پروکسی دانشگاه امیرکبیر (راه اندازی آسان)

**اینترنت دانشگاه را به یک VPN شخصی تبدیل کنید.** این پروژه اتصال دانشگاه شما را از طریق یک سرور مجازی (VPS) پل می‌زند تا اینترنت آزاد و بدون محدودیت را روی گوشی یا سایر دستگاه‌های شما فراهم کند. این سیستم به صورت خودکار اکانت‌های دانشجویی شما را مدیریت و جابه‌جا می‌کند تا همیشه بالاترین سرعت را داشته باشید.

---

## 📋 پیش‌نیازها (قبل از شروع)

1. **یک سرور مجازی (VPS) ایران**: به یک سرور لینوکس (اوبونتو/دبیان پیشنهاد می‌شود) در ایران نیاز دارید.
2. **پایتون (Python)**: باید پایتون (نسخه 3.4 یا جدیدتر) روی ویندوز شما نصب باشد.
    * *توجه: ویزارد راه‌اندازی برای اجرا به پایتون نیاز دارد، پس ابتدا آن را نصب کنید!*
3. **شبکه دانشگاه**: سیستم شما باید به شبکه دانشگاه امیرکبیر (AUT) متصل باشد.

---

## 🚀 شروع سریع (۳ مرحله)

### مرحله اول: راه‌اندازی سرور مجازی (Relay Server)

به سرور لینوکس ایران خود SSH بزنید و مراحل زیر را دنبال کنید.

#### الف. دانلود و استخراج

ابتدا دانلود خودکار را امتحان کنید. اگر به دلیل محدودیت‌های شبکه با خطا مواجه شدید، مسیر **دستی** را دنبال کنید.

**گزینه ۱: دانلود خودکار**

تلاش برای دانلود مستقیم از گیت‌هاب:
```bash
wget -O frp.tar.gz https://github.com/fatedier/frp/releases/download/v0.61.1/frp_0.61.1_linux_amd64.tar.gz
```

*اگر گیت‌هاب مسدود است*، از میرور ایرانی استفاده کنید:
```bash
wget -O frp.tar.gz https://scorpian.ir/proxy/asset/fatedier/frp/213672059
```

**گزینه ۲: دانلود دستی (اگر خودکار کار نکرد)**

1. فایل را روی کامپیوتر خود دانلود کنید:
   - [لینک رسمی گیت‌هاب](https://github.com/fatedier/frp/releases/download/v0.61.1/frp_0.61.1_linux_amd64.tar.gz)
   - [لینک میرور ایرانی](https://scorpian.ir/proxy/asset/fatedier/frp/213672059)
2. آن را در سرور آپلود کنید (نام فایل را به `frp.tar.gz` تغییر دهید).
    * **دستور آپلود (در کامپیوتر خود اجرا کنید):**
        ```bash
        # Note: Use :~/ to upload to your home folder
        scp C:\Path\To\frp.tar.gz username@YOUR_VPS_IP:~/
        ```
    * *یا از ابزارهایی مثل FileZilla یا WinSCP استفاده کنید.*

**پس از آپلود فایل در سرور، این دستورات را اجرا کنید:**

```bash
# استخراج، تغییر نام پوشه و پاکسازی
tar -xzf frp.tar.gz
mv frp_0.61.1_linux_amd64 frp
chmod +x frp/frps
rm frp.tar.gz
```

#### ب. ایجاد فایل پیکربندی

این دستور را برای ساخت کانفیگ سرور اجرا کنید:

```bash
echo "bindPort = 7000
kcpBindPort = 7000" > frp/frps.toml
```

#### ج. تنظیم شروع خودکار (سرویس)

کل این بلوک را کپی و پیست کنید تا سرویسی ساخته شود که با ری‌استارت سرور، خودکار اجرا شود:

```bash
sudo tee /etc/systemd/system/frps.service > /dev/null <<EOF
[Unit]
Description=FRP Server
After=network.target

[Service]
Type=simple
ExecStart=$(pwd)/frp/frps -c $(pwd)/frp/frps.toml
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
```

#### د. اجرا و بررسی

این دستورات را برای شروع سرویس و بررسی وضعیت اجرا کنید:

```bash
# 1. فعال‌سازی و شروع
sudo systemctl daemon-reload
sudo systemctl enable frps
sudo systemctl start frps

# 2. بررسی وضعیت (باید بنویسد active (running))
sudo systemctl status frps

# 3. بررسی پورت (باید پورت 7000 در حال LISTEN باشد)
sudo ss -tulpn | grep 7000
```

اگر خروجی‌ها درست بود، خواهید دید که سرویس `active (running)` است و پورت `7000` باز است. **🚀 سرور مجازی شما آماده است!**

---

### مرحله دوم: راه‌اندازی کامپیوتر (لوکال)

1. **انتخاب نسخه**: 
   * اگر کامپیوتر جدید دارید (ویندوز 10/11)، پوشه `VLESS_Server_64bit` را باز کنید.
   * اگر کامپیوتر قدیمی دارید (ویندوز 7 یا 32 بیت)، پوشه `VLESS_Server_32bit` را باز کنید.
2. **اجرای کنترل پنل اصلی**: درون پوشه انتخابی، فایل **`Start_Server.bat`** را اجرا کنید.
3. **راه‌اندازی تحت وب**: در اولین اجرا، اسکریپت مرورگر شما را باز کرده و به آدرس `http://127.0.0.1:3080` می‌رود.
4. اطلاعات زیر را وارد کنید:
   * **آی‌پی سرور مجازی (VPS IP)**
   * **نام کاربری و رمز عبور پورتال دانشگاه (AUT)**
   * **اطلاعات ورود داشبورد** (برای امنیت پنل مدیریت خود یک نام کاربری و رمز بسازید).
5. **نظارت یکپارچه**: پس از اتمام راه‌اندازی، تمام سرویس‌ها (Xray, FRPC و مدیریت اکانت) بلافاصله در یک پنجره واحد و رنگ‌بندی‌شده (Master Window) اجرا می‌شوند! دیگر خبری از دسکتاپ شلوغ نیست.

---

### مرحله سوم: اتصال گوشی

1. یک اپلیکیشن **سازگار با VLESS** روی گوشی خود نصب کنید (مثل **Karing**, **v2rayNG** یا **v2rayN**).
2. **لینک VLESS** که در پایان راه‌اندازی به شما داده می‌شود را کپی و در اپلیکیشن وارد کنید.
3. **متصل شوید** و از اینترنت آزاد لذت ببرید!

---

## 🛠 داشبورد و مدیریت

می‌توانید به صورت امن اکانت‌ها و سرورهای خود را از هر مرورگری مدیریت کنید:

* **دسترسی لوکال:** `http://127.0.0.1:3080`
* **دسترسی از راه دور (گوشی):** `http://YOUR_VPS_IP:8880`

### 🔄 نظارت و کنترل

* **لاگ‌های یکپارچه**: پنجره اصلی (Master Window) وضعیت زنده را با پیشوندهای رنگی نشان می‌دهد:
    * **`[XRAY]` (آبی)**: رویدادهای هسته شبکه.
    * **`[FRPC]` (قرمز)**: وضعیت اتصال تونل.
    * **`[AUTH]/[USAGE]`**: لاگ‌های مدیریت همزمان اکانت.
* **شروع فوری**: اسکریپت راه‌اندازی اکنون با استفاده از تشخیص پویای پورت‌ها، سرویس‌ها را در کسری از ثانیه لود می‌کند.
* **تعویض خودکار**: سیستم به طور خودکار بین اکانت‌های دانشجویی شما جابجا می‌شود تا همیشه بهترین سرعت (روزانه -> هفتگی -> ماهانه -> آزاد) را داشته باشید. نیازی به دخالت شما نیست!

### 🧹 چگونه تنظیمات را ریست کنم؟

اگر می‌خواهید تمام اطلاعات (رمزها/آی‌پی/کانفیگ‌ها) را پاک کنید، داشبورد وب را باز کرده و در پایین صفحه روی **Factory Reset** کلیک کنید. این کار همه چیز را پاک کرده و به شما اجازه می‌دهد `Start_Server.bat` را از نو اجرا کنید.

## ❓ رفع مشکلات احتمالی

* **اجرا نمی‌شود؟** مطمئن شوید پایتون نصب است (در هنگام نصب تیک "Add to PATH" را زده باشید).
* **اینترنت ندارید؟** مطمئن شوید فایروال سرور شما پورت‌های **7000** (KCP/FRP) و **8080** (VLESS) را باز گذاشته باشد.
* **رمز داشبورد را فراموش کرده‌اید؟** به صورت دستی پوشه `config` را پاک کنید، سپس دوباره `Start_Server.bat` را اجرا کنید.
